## 실행 방법

```powershell
cd backend
$env:DATABASE_ENABLED="false"; $env:RAG_EMBEDDING_PROVIDER="none"
.venv\Scripts\python.exe -m unittest discover -s tests
```

실 DB 통합까지 포함하려면 docker compose로 pgvector 기동 후 env 없이 실행(통합 클래스가 자동 감지, 미기동 시 skip).
