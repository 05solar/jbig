# chat/ — AI 상담 챗봇

| 파일 | 기능 |
|------|------|
| `page.tsx` | 서버 컴포넌트: `?lang`·`?guide=` 파라미터 처리, 가이드 정보를 서버에서 fetch해 클라이언트에 전달 |
| `chat-client.tsx` | 챗봇 UI 전체: 멀티턴 대화(직전 3개 질문을 conversation_context로 전송), 가이드 컨텍스트 배너·추천 질문, 커스텀 드롭다운(사용자 유형), 위치 버튼(지역 자동 입력, 권한 거부 시 안내), Enter 전송(IME 안전), 답변 모드 배지, 출처 카드(신뢰도·권위·확인일), 피드백(👍/👎 SVG), 429/연결 오류 처리 |
