# documents/ — 고용·행정 문서 검토

| 파일 | 기능 |
|------|------|
| `page.tsx` | 서버 컴포넌트 래퍼 (언어 파라미터 처리) |
| `document-client.tsx` | 문서 검토 UI 전체: 파일 업로드(PDF/이미지/TXT, 스캔본 동의 체크), 면책 문구, **표준 문서와 작성 방법** 섹션(근로계약서 체크리스트·임금명세서 가이드·계약 전 확인사항, 3개 언어), 결과 화면 — 문서유형·OCR 신뢰도 배지, 계약 내용 요약(주요 조건), 공식 기준과 다른 내용 요약, 위험 항목 카드(상단 상태바, 조항/공식기준/문제점/영향/권장수정/비교값 칩/확인목록/근거 출처), 상태코드별 오류 안내 |
